## Why this exists

Given the index, the agent reached for it in **22 of 117 calls (19 %)**. Five rounds have now recorded the same conclusion: tool *descriptions* do not make a model open a tool list it never looks at. [200](200_the-recognition-map-is-a-prompt-no-agent-can-read.md) is `blocked` on precisely this.

The skill exists — `contrib/skill/SKILL.md`, generated by `scripts/gen_skill.py` from the surface the server actually serves, drift-guarded, and already covering every shipped adapter suffix. Its problem is **location and shape**: it must be hand-copied to `~/.claude/skills`, so an agent working in a consumer repo never sees it; and it presents the **24-tool roster** when what earns its keep in the field is five occasions.

Good news for cost: the generator, the recognition-map source and the suffix coverage all exist. This ticket changes the destination and the shape, not the machinery.

## Scope / Deliverables

- **Write the brief into the indexed repo** after the first `build_or_update_index` (or from `scripts/setup.py`): an `AGENTS.md` section or `.cursor/rules/code-atlas.mdc` — the channel every agent on that repo reads.
- **Five occasions, not 24 descriptions.** Before renaming; after an edit; first session on the repo; a name that exists in two languages; writing the PR claim. Generated from the same `which_tool` source, so it cannot drift (R6.7).
- **Record the boundary in PLAN §19 before writing any code.** [036](036_edit-index-hook.md) / [099](099_write-time-signal-seam.md) established *offer, never install* — they forbid writing **editor settings**. Writing a file into the repo being indexed is a different act with a different blast radius. Without this recorded first, a reviewer reads 099 and blocks correctly.
- **Offered, not forced**: a flag or prompt controls it, existing content is never clobbered, and the written section is marked generated with its regeneration command.
- **Hook snippets stay offered** and keep covering every shipped suffix — a TypeScript edit must not silently rot the index (200's second defect).

## Constraints

- The server still **never** writes editor settings (036/099 unchanged).
- No hand-kept copy of the tool roster or the suffix list anywhere (R6.7) — the drift guard extends to the new artifact.
- No 25th tool, no `ask_graph`: consolidation was measured and rejected.

## Acceptance criteria

- A run against a fixture repo produces the five-occasion brief in that repo's tree, generated from `which_tool`, with a drift guard comparing committed bytes to the generator.
- Existing `AGENTS.md` content is preserved; re-running is idempotent.
- PLAN §19 carries the 036/099 boundary decision, committed **before** the code change.
- Every shipped adapter suffix appears in the offered hook snippet; a test derives the list from `shipped_adapters`.
