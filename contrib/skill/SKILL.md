# code-atlas — which tool answers which question

Generated by `scripts/gen_skill.py` from the 24 tools the server
registers and from the `which_tool` recognition map. Do not edit by hand: a drift guard
compares this file to its source, so a hand edit is a red test, not a quiet
disagreement.

## Recognition map

- Is the index built/fresh/healthy, what next? -> get_index_status (call first).
- Build or refresh the index -> build_or_update_index.
- Find a symbol by partial name/text -> search_symbol.
- What does a file define, and where -> file_outline.
- Read one symbol's source -> read_symbol.
- Who calls this function/method -> find_callers.
- Where is this symbol used -> find_references.
- Which types extend/implement this -> find_implementations.
- What variables a handler passes to its template -> find_view_data.
- What a file includes / what includes it -> include_graph.
- What breaks if I change this -> impact.
- Which modules does that change reach, and where to start -> impact_modules.
- Can this directory subtree be deleted — what crosses into/out of it -> subtree_dependencies.
- What is reachable from entry points / what is dead -> reachable_from.
- Which symbols look unused -> find_orphans.
- How does one symbol reach another -> explain_path.
- What are this codebase's layers, and how do they depend on each other -> architecture_overview.
- What should I read first, in dependency order -> guided_tour.
- How does this codebase route an incoming request to the code that produces the response -> trace_capability.
- What happens when a user does X — one request from entry to the data -> trace_capability.
- Write committable onboarding docs (overview, tour, per-module, manifest) -> generate_onboarding.
- Do the declared architecture rules hold — no forbidden edge, every required call made -> check_architecture_rules.
- What did the agent change about the architecture between two revisions -> diff_architecture.
- Render a class diagram for one type (plus ancestry) or one file -> class_diagram.
- Which writers of this table omit a column that has a DEFAULT -> check_column_defaults.

Call `get_index_status` first whenever you are unsure the index is current.

## What this skill is not

It carries the map, never a second set of tool descriptions — the descriptions the
client shows you are the ones that route, and a copy here could disagree with them.
It holds no live state either: index freshness, symbol counts and open work are what
the tools are for, and a number frozen into this file would be a wrong answer rather
than a stale one.
